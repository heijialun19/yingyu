🔒 隐私政策

我们不收集任何个人信息。具体而言：

✅ 无账号注册——不需要邮箱、手机号或任何身份信息
✅ 无 Cookie 追踪——不使用任何分析或广告追踪工具
✅ 无服务器存储——所有数据仅保存在你的浏览器本地（localStorage）
✅ 无第三方统计——不接入 Google Analytics、百度统计等
✅ 无社交登录——不需要微信、QQ 或任何第三方授权

关于未成年人：本站面向儿童使用，严格遵守《中华人民共和国未成年人保护法》和《儿童个人信息网络保护规定》，不收集未满 14 周岁儿童的任何个人信息。建议家长陪同孩子使用本站，并定期查看孩子的学习进度。

发音服务说明：点击单词播放发音时，浏览器会向第三方词典服务发起请求以获取音频。该请求由浏览器直接发出（与本站无关），仅包含所查询单词本身，不包含任何用户身份信息。

🔊 语音来源说明

本站发音只使用一种音源：公开词典发音服务（真人录音 MP3）。本站不使用任何机器合成语音。

发音请求由用户浏览器直接发起（与本站服务器无关），仅包含所查询单词本身，仅用于个人学习目的。

发音加载需要网络；离线状态下点击单词不会有声音。已听过的发音会被浏览器缓存，离线时可重复收听。

1. 建议每天使用 15 分钟，完成三个每日任务即可。过度使用电子设备不利于儿童视力健康。

2. 建议家长陪同前两周的使用，帮助孩子熟悉操作后逐步放手。

3. 本站进度数据保存在浏览器中，清除浏览器数据会丢失进度。请定期使用「家长中心 → 档案管理 → 备份与恢复」导出备份。

4. 如孩子在使用中遇到问题，可在「家长中心 → 语音诊断」排查，或通过 GitHub Issues 反馈。
