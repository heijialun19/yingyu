# 🐤 小鸟英语乐园 · Birdie ABC

> **🌐 官方网址（永久有效）：https://heijialun19.github.io/yingyu/**

专为**中国一年级起步的儿童（6-12岁）**设计的英语学习网站，覆盖**小学 1-6 年级 1000 个必背词汇**（参照义务教育英语课程标准，按年级分主题）。
- 单词方法：**字母象形·词源记忆法**（儿童版）—— a 是小鸟、W 是水波波、M 是大山……理解着记，不死记硬背
- 语法方法：**句子公式思维法**（儿童版）—— 句子小火车：谁 + 干什么 + 什么

## 🚀 怎么打开（三种方式）

**方式一（推荐，有网址）**：双击 `启动小鸟英语乐园.bat`——自动启动本地服务并打开浏览器访问 **http://127.0.0.1:8642** 。把这个网址收藏，或把 bat 发送到桌面快捷方式，孩子双击就能用。

**方式二（零依赖）**：直接双击 `index.html`，用 Edge 或 Chrome 打开，无需任何服务。

**方式三（发布到公网，手机/平板也能访问）**：
1. 注册 GitHub（免费）→ 新建仓库，上传本文件夹全部文件
2. 仓库 Settings → Pages → 选择 main 分支 → Save
3. 一分钟后得到公网网址 `https://你的用户名.github.io/仓库名/`，发给谁都能打开

> 语音朗读使用浏览器自带的语音合成（建议 Edge/Chrome）；每个小伙伴的学习进度独立保存在本机浏览器（按档案隔离），不上传任何数据；支持导出/导入备份换设备。

## 📁 文件结构

```
index.html      首页：学习地图 + 今日任务 + 每日复习提醒
letters.html    字母岛：26 个字母的象形故事 + 自然拼读（字母名 / 代表词，各读一遍）+ 拼音小桥梁
words.html      单词镇：6 个年级 × 61 个主题 = 1000 词，学认练玩 + 拆拆看 + 中英搜索 + 艾宾浩斯复习
grammar.html    句子工厂：万能公式 16 关（三阶段），第二阶段起造句题从单词镇词库实时生成
games.html      游戏乐园：听音选字母（名/音双模式）/ 图词翻翻乐 / 拼词小火车 / 句子火车员，优先复习学过的词
books.html      绘本馆：12 本连续故事绘本，点句子逐词真人朗读、翻页即预热、失败自动跳词
parents.html    家长中心：千词进度报告 + 各年级进度 + 方法论说明 + 使用建议
css/style.css   全站样式（零依赖）
js/words-data.js 小学 1000 词库（按年级分主题）
js/data.js      字母故事 / 语法关卡 / 徽章
js/app.js       共享运行时（进度存储 / 语音 / 音效 / 星星徽章 / 打卡）
js/sentence.js  句子朗读引擎（整句朗读 / 逐词高亮跟读）
sw.js           Service Worker：离线可用 + 发音缓存
```

## ✨ 核心特色

| 特色 | 说明 |
|---|---|
| 👤 多伙伴档案 | 一台电脑多个孩子各一份独立进度（名字+头像+年级），首次使用有引导；旧版进度自动迁移 |
| 💾 备份与恢复 | 导出/导入 JSON 备份文件，换电脑、清缓存进度不丢（导航栏头像 → 档案管理） |
| 🎓 年级主线（累计制） | 选一次年级：单词镇默认打开、游戏优先抽词、语法分阶段；**高年级自动涵盖低年级词汇**（Khan 式掌握制） |
| 🎯 我的词单 + 📓 错题本 | 自动汇总"本年级+低年级未掌握"的补漏词单；答错的词自动进错题本，针对性攻克 |
| 🔤 字母象形故事 | 每个字母是一个角色（元音会唱歌、辅音有含义）+ 自然拼读（字母名、代表词各读一遍） |
| 📚 1000 词分年级 | 1-6 年级 61 个主题全覆盖 + 中英搜索；**每个词都有记忆法拆解 + 词性小标签** |
| 🔊 单词双读 | 点一下单词：第一遍读完整发音，第二遍按自然拼读逐音拆读（cat → kuh-ah-tuh） |
| 🌉 拼音小桥梁 | 正面利用孩子刚学的拼音，标注中英读音差异，防 b/d/p/q 混淆 |
| 🚂 句子小火车 | 万能公式 16 关三阶段；造句题直接用单词镇的单词生成，学什么造什么 |
| 🎡 游戏与复习联动 | 4 个游戏优先抽"学过的词"复习；造句用到的单词自动进入艾宾浩斯计划 |
| 🔔 艾宾浩斯复习 | 答对自动排 1/2/4/7/15 天复习计划，每天最多 12 个不贪多，首页自动提醒 |
| ⭐ 星星徽章打卡 | 每日三任务（15分钟）、12 枚徽章、连续学习火焰 |
| 🎈 星星有处花 | 6 个限定头像用 30-120 ⭐ 解锁、永久有效；星星来自答题、拼写、游戏、全勤和复习 |
| ⏰ 护眼提醒 | 连续学习 15 分钟温和提醒休息、30 分钟建议收工；只统计页面可见时间，每档每天一次 |
| 🔒 安全纯净 | 纯静态、零依赖、无广告、无内购、数据只存本机 |
