小鸟英语乐园 · 离线版
================================================

版本：2026-11-08.3
打包：2026-11-08

------------------------------------------------
怎么用
------------------------------------------------
1. 把整个文件夹解压到任意位置
   （不要只解压 index.html —— 发音文件在 audio/ 目录里，缺了就没声音）
2. 双击 index.html，用 Edge 或 Chrome 打开

就这样。不需要联网、不需要装任何东西。
所有发音都在 audio/ 里：2864 个单词/字母/拼读块 + 497 句整句音频，完全离线。
发音全部由本站自己合成（同一个说话人），不含任何词典或教材网站的录音。


------------------------------------------------
里面有什么
------------------------------------------------
· 1000 个单词（按年级 / 主题分组，带中文、音标、记忆法）
· 26 个字母（字母岛：名称、发音、代表词）
· Get Smart 学堂：6 册 237 课，跟教材一课一课对上
  （学单词 → 闯关 → 句型 三步一课，还有复习课和单元小测）
· 19 关句子工厂（词性、三单、句型转换）
· 人教版课本：8 册 47 单元知识点 + 逐单元拼词
· 7 个游戏：听音选字母 / 图词翻翻乐 / 拼词小火车 / 句子火车员 /
            听句选图 / 造词实验室 / 拼读闯关
· 跟读打分（用浏览器语音识别，只判断"听清度"，不是发音评分）
· 家长中心：学习统计、档案管理、备份与恢复、版本与朗读诊断


------------------------------------------------
要注意的
------------------------------------------------
· 进度不会和线上版互通。
  线上是 heijialun19.github.io/yingyu，这里是本地文件，两边各存各的。
  想搬进度：家长中心 → 档案管理 → 备份，会生成一串同步码，另一边粘贴即可。
· 换浏览器、清除浏览器数据会丢进度，建议定期备份。
· 如果没声音：先到「家长中心 → 语音诊断 → 🎧 点我试听」确认设备音量；
  再确认 audio 文件夹和 index.html 在同一层。
· 发音不需要联网，但页面里那句「系统语音兜底」用的是电脑自带语音：
  极少数包里没有的内容才会用到它，声音会明显不同，属正常现象。
· 用 file:// 打开时没有 Service Worker（那是 https 才有的），
  但不影响任何功能，只是没有"装成 App"的离线缓存（本来就离线）。
· 所有固定内容（单词、字母、课本例句、课程例句）都有离线音频，断网照样能读。
  程序随机造出的句子按词拼接站内音频朗读，也不需要联网。


------------------------------------------------
这一版修了什么（2026-11-08.3 补派生词 + 许可补齐）
------------------------------------------------
· 补了 414 个「派生形态」的发音：eagles / jumps / doesn't / eating …
  句子工厂和句型游戏会临时造句子，句子里常有复数、三单、进行时，

  现在这些词形全部有音频，23 万词次随机出题扫描零遗漏。

  已缓存的设备不用重下。

  发音全部换成本站自合成（一个说话人、体积减 64%）；切断第三方发音接口；
