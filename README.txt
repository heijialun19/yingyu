小鸟英语乐园 · 离线版
================================================

版本：2026-10-29 交付版
打包：2026-10-31

------------------------------------------------
怎么用
------------------------------------------------
1. 把整个文件夹解压到任意位置
   （不要只解压 index.html —— 发音文件在 audio/ 目录里，缺了就没声音）
2. 双击 index.html，用 Edge 或 Chrome 打开

就这样。不需要联网、不需要装任何东西。
所有发音都在 audio/ 里（1231 个真人发音文件），完全离线。


------------------------------------------------
里面有什么
------------------------------------------------
· 1000 个单词（按年级 / 主题分组，带中文、音标、记忆法）
· 26 个字母（字母岛：名称、发音、代表词）
· 19 关句子工厂（词性、三单、句型转换）
· 6 个游戏：听音选字母 / 图词翻翻乐 / 拼词小火车 /
            句子火车员 / 听句选图 / 造词实验室
· 跟读打分（用浏览器语音识别，只判断"听清度"，不是发音评分）
· 家长中心：学习统计、档案管理、备份与恢复


------------------------------------------------
要注意的
------------------------------------------------
· 进度不会和线上版互通。
  线上是 heijialun19.github.io/yingyu，这里是本地文件，两边各存各的。
  想搬进度：家长中心 → 档案管理 → 备份，会生成一串同步码，另一边粘贴即可。
· 换浏览器、清除浏览器数据会丢进度，建议定期备份。
· 如果没声音：先点「我的 → 🎵 测试声音」确认设备音量；
  再确认 audio 文件夹和 index.html 在同一层。
· 用 file:// 打开时没有 Service Worker（那是 https 才有的），
  但不影响任何功能，只是没有"装成 App"的离线缓存（本来就离线）。


------------------------------------------------
这份版本包含哪些修复
------------------------------------------------
· 全站图标改成内置矢量图（617 个），不再依赖系统 emoji 字体
  → 老电脑（Win7/8）也不会出现黑白图标
· 所有图位统一淡色底
  → 白色系图案（牛奶/云/纸/蛋/冰/牙齿…）不会再"看不见"
· 去掉所有「猜你没听到声音」的自动弹窗
· 单词镇 / 翻翻乐 / 句子火车员 / 句子工厂的已知 bug 修复


------------------------------------------------
建议
------------------------------------------------
这份压缩包是「定版」，不会被任何人改动。
建议另存一份到网盘或 U 盘 —— 万一线上又被改乱了，用它恢复。
