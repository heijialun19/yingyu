小鸟英语乐园 · 离线版
================================================

版本：2026-11-08.17
打包：2026-11-08

------------------------------------------------
怎么用
------------------------------------------------
1. 把整个文件夹解压到任意位置
   （不要只解压 index.html —— 发音文件在 audio/ 目录里，缺了就没声音）
2. 双击 index.html，用 Edge 或 Chrome 打开

就这样。不需要联网、不需要装任何东西。
所有发音都在 audio/ 里：2864 个单词/字母/拼读块 + 497 句整句 + 39 个字母音与拼读块（母语者录音），完全离线。
发音全部由本站自己合成（同一个说话人），不含任何词典或教材网站的录音。

要注意的
------------------------------------------------
· 进度不会和线上版互通。
  线上是 heijialun19.github.io/yingyu，这里是本地文件，两边各存各的。
  想搬进度：家长中心 → 档案管理 → 备份，会生成一串同步码，另一边粘贴即可。
· 换浏览器、清除浏览器数据会丢进度，建议定期备份。
· 如果没声音：先到「家长中心 → 语音诊断 → 🎧 点我试听」确认设备音量；
  再确认 audio 文件夹和 index.html 在同一层。
· 发音不需要联网，但页面里那句「系统语音兜底」用的是电脑自带语音：
  极少数包里没有的内容才会用到它，声音会明显不同，属正常现象。
· 用 file:// 打开时没有 Service Worker（那是 https 才有的），
  但不影响任何功能，只是没有"装成 App"的离线缓存（本来就离线）。
· 所有固定内容（单词、字母、课本例句、课程例句）都有离线音频，断网照样能读。
  程序随机造出的句子按词拼接站内音频朗读，也不需要联网。

这一版修了什么（2026-11-08.8 拼读闯关重做）
------------------------------------------------
· 拼读闯关（游戏里的 🔤）重做了。以前是「听一个整词，从 4 个同族词里选出来」，
  选项还把单词印在脸上——孩子只要认字就行，学不到拼读。
  现在改成真正的拼读训练：
    听 → 一个音一个音地播 /k/ … /æ/ … /t/（不是 /kæt/）
    拼 → 从字母块里按顺序点出 c、a、t（点一个块就发那个块的音）
    成 → 拼对后先听拆开的音、再听整词，屏幕上显示「c · a · t 连起来就是 cat」
  133 个词条里 98 个能这样拼；剩下的（rabbit、thumb、egg、cake 这类
  拼写和读音对不上的）改成「听词选图」，只给图不给单词，也只能靠听。
· 用上了新做的 26 个字母音——拼 c-a-t 时读的是 /k/ /æ/ /t/，
  和字母岛教的是同一套音。

上一版修了什么（2026-11-08.7 导航重排 + 真字母音）
------------------------------------------------
· 底部导航把「字母」换成「语法」：句子工厂（语法）现在随手可进。
  字母岛没有取消 —— 首页的岛屿卡片里一直有它的入口，没学完字母时会排在前面。
· 句子工厂不再按年级标注了。以前每关下面写着「一年级 / 二年级 / 三年级+」，
  别的年级的孩子看了会觉得"这不是我的"而不肯学。现在只按难度分组：
  句子公式 / 用单词造句 / 进阶句型。
· 字母岛的「📢 字母音」终于读的是**字母自己的音**了：
  以前点它读的是 apple / ball 这些代表词，孩子听到的是 /æpl/，学不到 /æ/。
  现在 A 读 /æ/、B 读 /b/、X 读 /ks/，26 个字母各一个音，和全站同一个声音。
  点「🎵 完整口诀」会依次读：字母名 → 字母音 → 例词。
  （辅音单独发不出声，所以 /b/ 实际是短促的"buh"，这是自然拼读通用的教法）

上一版修了什么（2026-11-08.6 教学内容大校对）
------------------------------------------------
这一版只做一件事：把「教错」的地方改对。查了词库、音标、语法关、
自动出题、人教版知识点五处，逐条读出来的问题：
· 词性错了 82 处：课堂用语整个主题 20 个词被标成动词（word/sentence 都成了动词），
  运动主题把 skate/ride/throw 标成名词，商店主题把 buy/sell/pay 标成名词，
  be 动词 am/is/are 标成代词，and/or/but 标成介词……现在逐词校正。
· 音标错了 35 处：giraffe 标成重音在第一个音节、thirteen 标了两个主重音、
  biscuit/ticket/jacket/rabbit 把 -ɪ- 写成 -ə-、toothbrush 的 brush 写错、
  usually 多了一个 w……已按标准美音改正。
· 自动出题会教错英文：不可数名词被套上 a/an 和复数，出现
  "There is a chicken over there."（那边有一只鸡，可这个站的 chicken 是"鸡肉"）、
  "This is a lunch."、"two breakfasts"；中文量词也全按"一个"套，
  出现"一个飞机""一个自行车""两个奶牛""两个鸡肉"。现在不可数词被挡在模板外，
  量词按词精确（架/艘/辆/本/支/朵/头/匹/颗…）。
· 自动出题的中文是病句：「她不有饺子」「它不有书包」「她不看见熊」——
  否定句模板把"不"直接接在"有/看见"前面。已改成"没有/看不见"，
  否定句末尾也不再误用问号。
· 语义荒谬：小猫在飞、秋千在床上、自行车在椅子上、
  介绍家人却出 "This is a mom."。已按主题和动词合理搭配。
· 单词页「跟读」是三个死模板：I see a apple. / This is cat. / I like apple.
  跟读要孩子开口念，念错句比看错句更糟。现在按词的语法属性生成
  （a/an 看读音、可数才加复数、形容词动词不进来）。
· 人教版知识点 273 张卡逐条核对：中英例句一一对应、问号句号一致，
  修掉一处笔误。
